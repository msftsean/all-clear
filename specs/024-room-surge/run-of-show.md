# Run of show: Room Surge (Use Case Showcase, 7 minutes)

**Setup (before lunch)**: projector on `/surge?key=…&join=<short-url>` (board CLOSED,
quiet). Cards on tables: A to D spread so each event lands on 3–4 tables; one E and
one R card per room. Backup tab open on `/?demo=loaded`.

| Time | Beat | Say (roughly) |
|---|---|---|
| 0:00 | The problem | "A water main breaks and forty people report the same outage. Responders drown in duplicates. Let's make that happen, right now, in this room." |
| 0:45 | Cards | "Everyone has a card. Same events, your words. Don't copy the card, and leave out names or phone numbers. Red card? Try to break it." |
| 1:15 | **Open** | Click Open. "Scan and report. Go." Stay quiet for about 60 seconds and let the counters climb. |
| 2:30 | The collapse | Point at Signals vs Incidents and the ratio. "Every one of those reports is kept. The board shows what's actually happening." |
| 3:15 | Red card | Point at "blocked by safety". "Somebody tried to talk it out of its rules. Severity comes from fixed rules, not the model. You can't sweet-talk a rule." |
| 4:00 | Close + receipt | Click Close. Open one Incident's decision receipt in the main UI: severity, SLA, rules applied, approval gate. |
| 5:00 | Value | Tracy's value scale: today Automate, heading to Redesign. "Measured in throughput: one clear board instead of 40 duplicates." |
| 6:30 | Bridge | "Tomorrow you can build this." |

**Honesty notes**: the card letter never reaches routing, so the collapse comes from
the language and the deterministic router, not the card. If coaches seed reports,
say so.

**Fallback ladder**: live surge → `/?demo=loaded` replay (Muni Water, 40 signals) →
backup demo (outbound call + multilingual) → mock mode.
