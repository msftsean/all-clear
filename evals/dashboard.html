Security findings

Statuses distinguish a fixed code path from a protected-but-disabled feature. Neither establishes complete application-wide authorization. Guardian completed an independent local review; live deployment and gateway behavior remain unverified.

  • Severity: HIGH Session access control · Protected / disabled

    Both session GET routes return 503 and the frontend no longer requests history. This is fail-closed disablement, not ownership authorization. Voice sessions are still persisted using a shared identity; keep history disabled until a verified principal and server-side tenant/session ownership exist.

    Reference: backend/app/api/sessions.py:25-45; frontend/src/allclear/ConversationHistory.tsx · confidence 9/10.

  • Severity: HIGH Transcript exposure · Protected / disabled

    The public SSE route returns 503; the ACS media WebSocket closes with 1008 before obtaining an Azure token. Redaction now runs before bus publication, but phone bridging/transcript display is disabled, internal bus subscription can still be unfiltered, and call-ID filtering is not authorization.

    Reference: backend/app/api/transcripts.py:32-40; backend/app/api/media_ws.py:467-473 · confidence 9/10.

  • Severity: MEDIUM Client-controlled realtime instructions/session ID · Fixed

    The handler generates a fresh session ID and passes the fixed safety prompt; the Azure service also hardcodes that prompt. The caller-controlled prompt/session path is no longer used.

    Reference: backend/app/api/realtime.py:202-231; backend/app/services/azure/realtime.py:137 · confidence 8/10.

  • Severity: MEDIUM PII signal lost before deterministic escalation · Fixed

    Both Lab 07 servers now capture trusted PII metadata before redaction and pass it separately into the Lab 05 pipeline. The router preserves escalation without sending detected source text to the model. Detection is limited to patterns recognized by the shared redactor; this is not comprehensive PII/PHI detection.

    Reference: labs/07-mcp-server/{start,solution}/mcp_server.py:124-153; labs/05-agent-orchestration/solution/pipeline.py:121-145 · confidence 9/10.

Broader auth-scope uncertainty: Guardian found no general end-user authentication dependency on the reviewed application routes; which routes are intentionally public and whether a deployment gateway adds protection are unknown. This is an unresolved integration/authorization question, not a severity-rated finding in this report. Inventory route exposure and enforce verified identity/ownership for tenant- or operator-scoped actions before multi-tenant production use.
