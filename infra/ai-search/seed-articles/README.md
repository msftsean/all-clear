# All Clear operational seed articles

These neutral operational articles seed the development Azure AI Search index.
They support the All Clear incident-triage workflow rather than any
organization-specific support model.

- `incident-response.json` covers field safety, public communication,
  compliance, and engineering response.
- Every article uses an All Clear queue (`field-operations`,
  `customer-comms`, `compliance-desk`, `engineering`, or `escalations`).
- Production deployments must replace this demo corpus with approved,
  jurisdiction-appropriate operational guidance.
